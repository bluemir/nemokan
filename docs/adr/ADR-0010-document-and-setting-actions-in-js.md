# ADR-0010: 문서 동작과 앱 설정 동작은 JS 가 처리한다

## Status

Accepted

## Date

2026-10-25

## Context

ADR-0005 에서 JS 는 키와 툴바 이벤트를 동작으로 바꿔 Go 에 넘기기로 했다. 원본의 동작 중 다음 두 묶음은 Go 가 할 일이 거의 없다.

- 문서 동작: 새 문서, 전환, 삭제, 이름 변경, 파일로 저장, 파일 열기, 내보내기
	- 대부분 로컬 저장소를 읽고 쓴다. ADR-0007 에서 저장소는 JS 가 맡기로 했다.
	- 파일 저장과 열기는 브라우저 파일 API 를 쓴다.
- 앱 설정 동작: 글자 크기, 서식 패널 보이기, 단축키 도움말
	- UI 상태만 바꾼다.

이 동작들을 Go 로 보내면, Go 는 다시 JS 에 저장소나 UI 일을 부탁해야 해서 왕복만 생긴다.

## Decision

**문서 동작과 앱 설정 동작은 Go 로 보내지 않고 JS 가 처리한다. 계산이 필요한 부분만 Go 함수로 부른다.**

- Go 가 제공하는 것
	- 선택한 도형 또는 전체를 텍스트로 내보내기
	- 현재 도형으로 파일(ADR-0004 의 `File`) 내용 만들기
	- 파일 내용 읽기와 적용 (그대로 열기, 새 ID 의 사본으로 열기)
	- 빈 새 문서로 바꾸기, 저장소에서 읽은 문서 복원 (ADR-0007)
- JS 가 맡는 것
	- 문서 목록, 이름, 화면 위치, 마지막으로 연 시각을 IndexedDB 에 저장
	- 파일 저장과 열기 (브라우저 파일 API)
	- 같은 ID 의 문서가 있을 때 묻는 `<dialog>` (둘 다 두기, 바꾸기)
	- 글자 크기, 서식 패널, 단축키 도움말
- 텍스트로 복사(`copyText`)는 Go 가 클립보드 텍스트를 만드는 일이라 Go 동작으로 둔다.
- Go 의 `action` 패키지에서 문서 동작과 앱 설정 동작 타입을 뺀다.

## Consequences

- JS 에서 Go 로 들어오는 입구가 동작 하나만은 아니게 된다. 대신 왕복이 없다.
- 원본의 `FileRelatedActionsHelper`, `AppSettingActionHelper` 는 대부분 JS 코드가 된다.
