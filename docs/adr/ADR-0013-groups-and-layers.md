# ADR-0013: 그룹과 레이어는 Mockdown 처럼 다룬다

## Status

Accepted

## Date

2026-11-02

## Context

원본 MonoSketch 에는 그룹 모델(`Group`, `GroupShapes`, `Ungroup`)과 작업 그룹(`workingParentGroup`)이 있지만, 그룹을 묶는 UI 가 없다. 캔버스 선택도 그룹을 모르고 맨 안쪽 도형을 고른다.

Mockdown 을 참고해 그룹 묶기·풀기와 레이어 패널(순서 바꾸기, 그룹 안팎으로 옮기기, 숨기기, 잠그기, 이름 바꾸기)을 넣기로 했다. 정해야 할 것은 다음과 같다.

- 그룹 안의 도형을 캔버스에서 어떻게 고르는가
- 숨기기, 잠그기, 이름을 어디에 두고 무엇을 막는가
- 파일 형식을 어떻게 바꾸는가

## Decision

**캔버스 선택은 Mockdown(그리고 Figma)과 같이 작업 그룹 단위로 하고, 이름·숨김·잠금은 모든 도형의 공통 값으로 파일에 저장한다.**

- 캔버스 선택
	- 클릭과 영역 선택은 작업 그룹의 항목을 고른다. 그룹 안의 도형을 누르면 그 도형을 품은 그룹이 통째로 골라진다.
	- 고른 그룹을 더블클릭하면 그 그룹이 작업 그룹이 되고, 마우스 아래 항목이 골라진다.
	- 작업 그룹 밖을 클릭하면 작업 그룹이 맨 위(root)로 돌아간다.
	- 레이어에서 도형을 고르면 그 도형을 품은 그룹이 작업 그룹이 된다.
	- 그룹은 크기를 바꿀 수 없다. 범위만 보이고, 옮기면 안의 도형이 함께 옮겨진다.
	- 단축키는 Cmd/Ctrl+G (묶기), Cmd/Ctrl+Shift+G (풀기)
- 숨기기
	- 숨긴 도형과 숨긴 그룹 안의 도형은 그리지 않고, 마우스로 찾지 않고, 고를 수 없다. 숨기면 선택에서 빠진다.
	- 내보내기(Markdown, SVG, PNG, 텍스트)와 텍스트로 복사에서도 빠진다. 도형 복사와 붙여넣기는 숨김 값을 그대로 옮긴다.
- 잠그기
	- 캔버스에서만 막는다. 잠근 도형과 잠근 그룹 안의 도형은 클릭, 영역 선택, 전체 선택으로 고를 수 없고, 마우스와 방향키로 옮기거나 크기를 바꿀 수 없다.
	- 레이어에서는 고를 수 있고, 속성 패널에서 고치거나 순서를 바꾸고 지울 수 있다.
- 이름은 비어 있으면 기본 이름을 보인다. 텍스트는 첫 줄, 나머지는 종류(Rectangle, Line, Group)다.
- 파일 형식
	- 모든 도형에 `name`, `isHidden`, `isLocked` 를 더한다. 값이 없으면 적지 않으므로, 전에 저장한 파일도 그대로 읽힌다.
	- 숨김과 잠금은 도형 자신의 값만 저장한다. 그룹 안의 도형이 숨겨졌는지는 그룹을 따라 올라가며 계산한다.
- 레이어에서 옮기기(`MoveShape`)
	- 그룹을 자기 자신이나 자기 안으로 옮길 수 없다.
	- 옮긴 뒤 원래 그룹에 항목이 하나만 남으면 그룹을 풀고, 하나도 없으면 지운다. `RemoveShape` 와 같다.

## Consequences

- 전에는 그룹 안의 도형을 바로 골랐지만, 이제는 더블클릭으로 그룹에 들어가야 한다. 지금까지 그룹을 만드는 UI 가 없었으므로 기존 문서에는 영향이 거의 없다.
- 숨김·잠금 값이 있는 파일은 이 기능이 없는 이전 버전에서 그 값이 무시된다.
- 원본 MonoSketch 의 파일 형식과는 더 멀어진다. 이미 ADR-0004 에서 호환하지 않기로 했다.
