## Mockdown 에서 가져오기

[Mockdown](https://github.com/bbssppllvv/Mockdown) 을 참고한다. 자유 그리기 도구는 넣지 않는다.

- [x] 화면 배치와 시각 스타일을 Mockdown 처럼 바꾸기
	- [x] 왼쪽 세로 도구 막대 (도구를 묶음별로 나열)
	- [x] 오른쪽 속성 패널 (지금의 서식 패널을 옮겨 합침)
	- [x] 아래 상태 막대 (현재 도구, 커서 위치)
	- [x] 색, 글꼴, 버튼 모양
- [x] 내보내기
	- [x] Markdown 복사 (텍스트를 ``` 코드 블록으로 감싸 복사)
	- [x] SVG, PNG 파일로 내려받기. 고른 도형이 있으면 그것만, 없으면 문서 전체를 내용이 있는 범위로 잘라서
	- [ ] SVG 는 D2Coding 이 없는 곳에서 다른 고정폭 글꼴로 보임. 글꼴을 SVG 에 넣을지 결정 (D2Coding 전체는 수 MB, 쓰인 글자만 넣으려면 글꼴 자르기가 필요)
- [x] 그룹과 레이어
	- [x] 그룹 묶기, 풀기
	- [x] 레이어 패널 (순서 바꾸기, 그룹 안팎으로 옮기기)
	- [x] 레이어 숨기기, 잠그기, 이름 바꾸기 (파일 형식에 값 추가)
		- ADR-0013
	- [x] 레이어 행의 이동 버튼으로 그 도형을 고르고, 화면 밖이면 가운데로 옮기기
	- [ ] 레이어 패널 행을 키보드로 고르고 다루기 (지금은 마우스만 됨)
	- [ ] 읽기 전용 문서에서 레이어 패널 보이기 (지금은 속성 패널과 함께 감춤)
- [x] UI 요소를 새 도형 종류로 추가 (Mockdown 의 19가지 전부)
	- 버튼, 입력칸, 카드, 표, 모달, 체크박스, 라디오, 드롭다운, 토글, 탭, 검색, 진행 막대, 경로(breadcrumb), 페이지 번호, 내비게이션, 목록, 빈 칸 표시(placeholder), 좌우 나누기, 이미지 칸
	- 내용은 속성 패널과 캔버스 더블클릭 둘 다에서 고치기
