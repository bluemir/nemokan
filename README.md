# nemokan

nemokan (네모칸, "square cells") is an editor for drawing diagrams and UI wireframes as text.
Copy them as Markdown for documents, issues and AI agents, or download them as SVG or PNG.

nemokan is based on [MonoSketch](https://github.com/tuanchauict/MonoSketch) by Tuan Chau
([commit 6eeb753](https://github.com/tuanchauict/MonoSketch/tree/6eeb753b436509e49507a66344be5c53c890e8f5)),
ported from Kotlin/JS to Go. The editor runs as Go WebAssembly in the browser.
The user interface and the UI elements are inspired by [Mockdown](https://github.com/bbssppllvv/Mockdown).

## Run

```sh
make run
```
